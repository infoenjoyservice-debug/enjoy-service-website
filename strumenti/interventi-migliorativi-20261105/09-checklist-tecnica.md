# Checklist tecnica finale

- [ ] Ogni pagina ha un H1 coerente con il proprio intento
- [ ] Canonical autoreferenziale sulle pagine uniche
- [ ] Nessun canonical usato per "risolvere" una semplice sovrapposizione di keyword
- [ ] Meta description uniche
- [ ] Internal linking coerente con la gerarchia
- [ ] Breadcrumb coerenti
- [ ] Schema LocalBusiness coerente con l'attività reale
- [ ] Servizi tramite partner distinti dai servizi diretti
- [ ] Recensioni reali e verificabili
- [ ] Nessun AggregateRating inventato
- [ ] Form con informativa privacy e consenso dove necessario
- [ ] Portfolio con contenuti originali
- [ ] Evitare la proliferazione di pagine città × servizio quasi identiche
