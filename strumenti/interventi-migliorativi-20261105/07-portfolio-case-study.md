# Portfolio / Lavori

Trasformare progressivamente i lavori più importanti in mini case study.

Struttura:
- Titolo intervento
- Zona
- Tipo di immobile
- Servizio
- Problema iniziale
- Intervento eseguito
- Risultato
- Foto Prima/Dopo
- Link al servizio pertinente

Esempio:
"Pulizia post-ristrutturazione di un appartamento a Milano"

Questo contenuto è preferibile alla creazione massiva di pagine locali quasi identiche.
