# Checklist prima della pubblicazione

## SEO
- [ ] Title unico
- [ ] Meta description unica
- [ ] Un H1
- [ ] H2 coerenti
- [ ] URL leggibile
- [ ] Canonical corretto
- [ ] Indexability verificata
- [ ] Internal link in entrata
- [ ] Internal link verso pagina contatti/servizio
- [ ] Immagini compresse
- [ ] ALT descrittivi e non keyword stuffing

## Structured data
- [ ] JSON-LD coerente con contenuto visibile
- [ ] Nessuna recensione inventata
- [ ] FAQ realmente presenti nella pagina
- [ ] Validazione schema

## Local
- [ ] Comune realmente servito
- [ ] Dati NAP verificati
- [ ] GBP coerente
- [ ] Case study locale reale, se dichiarato

## Conversione
- [ ] CTA visibile
- [ ] Telefono
- [ ] WhatsApp
- [ ] Form con campi utili
- [ ] Privacy
