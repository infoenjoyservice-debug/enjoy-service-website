# Enjoy Service SRL — SEO TOP v2

Obiettivo: portare il sito da una buona base SEO a una struttura più forte su servizi, local intent, autorevolezza, prove reali e conversioni.

## Principi
- Non usare keyword stuffing.
- Pubblicare solo informazioni, foto, recensioni e risultati reali.
- Mantenere trasparente la distinzione tra servizi gestiti direttamente e servizi coordinati tramite partner qualificati.
- Evitare pagine locali quasi duplicate.
- Misurare prima/dopo con Google Search Console e analytics.

## Priorità
1. Pagine money: Milano, Cinisello, uffici, condomini, appartamenti, post-ristrutturazione, vetri, amministratori di condominio, Monza.
2. 10+ case study reali.
3. Recensioni autentiche integrate nelle pagine commerciali.
4. Google Business Profile + citazioni locali + coerenza NAP.
5. Search Console: query, CTR, posizione, lead.
6. Schema JSON-LD validato prima della pubblicazione.

Questa release è integration-ready: i testi e gli asset sono separati dal codice del sito per consentire l'integrazione senza imporre un framework specifico.
