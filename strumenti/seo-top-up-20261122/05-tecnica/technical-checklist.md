# Technical SEO checklist

## Indexing
- [ ] Search Console verificata
- [ ] Sitemap XML presente e inviata
- [ ] robots.txt verificato
- [ ] Nessuna pagina importante con noindex
- [ ] Canonical coerenti
- [ ] HTTPS uniforme
- [ ] Redirect 301 controllati
- [ ] 404 monitorati
- [ ] URL canonici e leggibili

## On-page
- [ ] Un H1 per pagina
- [ ] Title unico
- [ ] Meta description unica
- [ ] Breadcrumb
- [ ] Internal linking
- [ ] Immagini compresse
- [ ] ALT descrittivi
- [ ] Open Graph
- [ ] favicon / manifest, se necessario

## Performance
- [ ] LCP
- [ ] INP
- [ ] CLS
- [ ] mobile first
- [ ] lazy loading immagini non above-the-fold
- [ ] WebP/AVIF dove supportato
- [ ] font ottimizzati
- [ ] script di terze parti minimizzati

## Structured data
- [ ] LocalBusiness
- [ ] Service
- [ ] BreadcrumbList
- [ ] FAQPage solo dove appropriato
- [ ] Organization, se utile

## Tracking
- [ ] GA4
- [ ] Search Console
- [ ] click telefono
- [ ] click WhatsApp
- [ ] invio form
- [ ] click email
