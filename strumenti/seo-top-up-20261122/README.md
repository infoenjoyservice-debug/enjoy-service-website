# Enjoy Service — SEO TOP Upgrade Pack

Pacchetto integrativo: non sostituisce il sito attuale.
Obiettivo: trasformare l'attuale presenza web di Enjoy Service in una struttura SEO + Local SEO + conversione più forte.

## Priorità
1. Google Business Profile + NAP consistency
2. Home + Cinisello + Milano
3. Money pages: uffici, condomini, amministratori, post-ristrutturazione, appartamenti, vetri
4. Case study / prima-dopo
5. Internal linking
6. Schema.org / dati strutturati
7. Search Console + analytics + Core Web Vitals
8. Espansione locale controllata

## Regola fondamentale
Non creare pagine locali duplicate cambiando soltanto il nome della città. Ogni pagina local deve contenere informazioni, prove, lavori, FAQ e riferimenti realmente pertinenti alla zona.

## Nota tecnica
Prima del deploy fare un backup completo e verificare:
- URL già indicizzati
- redirect esistenti
- canonical
- sitemap
- robots.txt
- Search Console
- Google Business Profile
- GA4 / tracking conversioni

Questo pacchetto contiene testi e template pronti da adattare; non va pubblicato alla cieca senza verificare i dati aziendali reali.
