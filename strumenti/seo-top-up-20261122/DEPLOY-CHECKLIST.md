# Deploy checklist

Prima della pubblicazione:
- [ ] Backup del sito
- [ ] Verifica URL esistenti
- [ ] Verifica redirect
- [ ] Verifica canonical
- [ ] Verifica sitemap
- [ ] Verifica robots
- [ ] Verifica schema con strumenti ufficiali
- [ ] Verifica Search Console
- [ ] Verifica form e WhatsApp
- [ ] Verifica tracking
- [ ] Test mobile
- [ ] Test velocità
- [ ] Controllo ortografia e dati aziendali
- [ ] Controllo GDPR/privacy/cookie
- [ ] Richiedere nuova scansione delle pagine modificate
