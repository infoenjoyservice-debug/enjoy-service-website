# Integrazione Reteimprese — Enjoy Service SRL

Pacchetto integrativo per il sito:
https://enjoy-service-cinisello-balsamo.netlify.app/

## Contenuto

- `reteimprese-badge.html` — snippet HTML pronto da inserire.
- `reteimprese-badge.css` — stile minimo e responsivo.
- `README.txt` — queste istruzioni.

## Dove inserirlo

La pagina attuale contiene la sezione "Azienda". Il badge può essere inserito
alla fine del blocco "Chi siamo", prima della sezione "Dove operiamo", oppure
nel footer se si preferisce una presenza più discreta.

## Nota

Il badge utilizza direttamente l'immagine ufficiale indicata nel codice e
rimanda alla scheda Reteimprese dell'attività.

Se il sito è gestito come singola pagina HTML, è sufficiente copiare il
contenuto di `reteimprese-badge.html` nel punto desiderato e, se necessario,
aggiungere il CSS di `reteimprese-badge.css` al foglio di stile principale.
